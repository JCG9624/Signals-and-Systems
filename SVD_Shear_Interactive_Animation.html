Learning outcomes

The eigenvalues stay fixed: A is triangular, so λ₁ = λ₂ = 1 whatever a is.

The singular values measure stretching: σ₁ ≥ 1 and σ₂ ≤ 1, even though neither eigenvalue changes.

Area is preserved: det A = σ₁σ₂ = 1. One direction stretches, the perpendicular one contracts.

The four diagrams use the same coordinate scale. The pale dashed circle is the original unit circle (a reference). At a = 0, both singular values equal 1, so the singular-vector directions are not unique; a continuous choice is shown. Works offline in any modern browser.
