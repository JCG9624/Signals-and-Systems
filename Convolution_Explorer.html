Circuit models. RC measures capacitor voltage. The series RLC circuit measures capacitor voltage (low-pass), resistor voltage (band-pass) or inductor voltage (high-pass), with ωₙ = 1/√(LC) and ζ = (R/2)√(C/L). K = 1 gives the circuit voltage ratio; other K values scale it.

Initial conditions. These are causal impulse-response models, at rest before the input is applied. The original MATLAB example is two-sided: its past input is included, so y(0) = 2 for the default integrator example. For inputs with jumps and systems containing impulses, the plotted output uses the input value just after each jump.

Impulsive systems. The inductor impulse response contains Kδ(t), producing the instantaneous term Kx(t). A finite train of N impulses at 0, T, …, (N − 1)T produces N delayed copies of the input. Each impulse contribution is its weight multiplied by the input sampled at the corresponding time.

Numerical display. The output uses exact linear-state propagation to floating-point precision. Regular signed areas use numerical quadrature; Dirac impulse contributions use exact weighted samples. Any area beyond the visible τ window is reported below the plot.
